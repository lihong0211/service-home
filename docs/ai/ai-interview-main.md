# LLM、VLM、RAG 与 Agent 面试高频速查

> 共 80 题。建议先遮住答案，用 1～3 分钟口述。  
> `★★★` 必须掌握；`★★` 常见进阶；`★` 岗位相关。

## 一、LLM 核心原理

### 1. `★★★` 自注意力如何工作？

**口述答案：** Q 与 K 点积计算相关性，除以 `√d_k` 后做 Softmax，再对 V 加权求和。它允许所有位置并行交互，长距离路径短；代价是标准注意力对序列长度为 `O(n²)`。

### 2. `★★★` 为什么需要位置编码？

**口述答案：** 自注意力本身不知道顺序，必须注入位置信息。常见有绝对位置、相对位置、RoPE 和 ALiBi；选型重点是长度外推、训练稳定性和推理成本。

### 3. `★★★` RoPE 的核心是什么？

**口述答案：** 按位置旋转 Q/K，使点积包含相对位置。它参数开销小、适合相对位置表达，但超过训练长度仍可能退化，需要缩放策略；不能说 RoPE 天然支持无限上下文。

### 4. `★★★` MHA、MQA、GQA 的区别？

**口述答案：** MHA 每个头独立 K/V；MQA 所有 Query 头共享 K/V；GQA 分组共享。KV Cache 从大到小通常是 MHA、GQA、MQA，质量与速度则需要折中。

### 5. `★★★` 三类 Transformer 架构如何选？

**口述答案：** Encoder-only 擅长理解与表示；Decoder-only 擅长自回归生成；Encoder-Decoder 擅长条件生成。通用 LLM 多用 Decoder-only，因为训练目标统一、扩展性好，不代表所有任务绝对最优。

### 6. `★★` Pre-Norm 为什么更常见？

**口述答案：** Pre-Norm 在子层前归一化，残差梯度路径更直接，深层模型训练更稳定。Post-Norm 可能表达更强，但对初始化和优化更敏感。

### 7. `★★` RMSNorm 与 LayerNorm 的区别？

**口述答案：** LayerNorm 做中心化和缩放；RMSNorm 只按均方根缩放，计算更简单。许多 LLM 使用 RMSNorm，在保持效果的同时减少少量开销。

### 8. `★★` 为什么常用 SwiGLU？

**口述答案：** SwiGLU 用门控分支控制信息流，通常比普通 GELU FFN 表达力更强。代价是额外投影参数，因此会调整中间维度控制总参数量。

### 9. `★★` BPE、WordPiece、SentencePiece 的区别？

**口述答案：** BPE 合并高频符号对；WordPiece 依据似然类目标选择子词；SentencePiece 是直接从原始文本训练 BPE/Unigram 的框架。实际还要比较压缩率、多语言、数字和代码切分。

### 10. `★★` Scaling Laws 的工程意义？

**口述答案：** 损失随参数、数据、计算呈经验幂律。固定预算下要联合配置模型大小和训练 Token，而非只堆参数；规律受数据质量和架构影响，不能无限外推。

### 11. `★★` 如何理解涌现能力？

**口述答案：** 某些能力随规模增长看似突然出现，但离散指标也会制造“突变”。不应背一个统一参数阈值，应讨论能力增长与测量方式。

### 12. `★★` MoE 为什么计算量没有随总参数同比增长？

**口述答案：** 路由器让每个 Token 只激活少数专家。主要难点是负载不均衡、容量溢出和跨设备 All-to-All 通信。

## 二、训练、微调与对齐

### 13. `★★★` 预训练、持续预训练和 SFT 的区别？

**口述答案：** 预训练学习通用语言分布；持续预训练注入领域语言和知识；SFT 学习任务行为与指令遵循。动态事实优先 RAG，行为格式优先 SFT。

### 14. `★★★` LoRA 的原理？

**口述答案：** 冻结原权重，用两个低秩矩阵学习权重增量。它减少可训练参数和优化器显存；rank、目标模块、学习率必须用验证集选择，不是越大越好。

### 15. `★★` QLoRA 为什么省显存？

**口述答案：** 基础模型低比特存储并冻结，只训练 LoRA；计算时按需反量化。省的是权重和优化器相关显存，不代表所有计算都是真正 4-bit。

### 16. `★★★` 多轮 SFT 中哪些 Token 算 Loss？

**口述答案：** 通常只计算 Assistant 输出，系统、用户和工具结果作为条件并掩码。模板边界或掩码错误会导致角色混乱、复述用户或停止异常。

### 17. `★★★` 如何构建高质量 SFT 数据？

**口述答案：** 先管合法来源和隐私，再做清洗、去重、质量评分、难度与任务分层、人工抽检和泄漏检测；最后通过固定评测集与消融证明数据收益。

### 18. `★★` Loss 下降但业务效果不升，为什么？

**口述答案：** 目标不一致、数据泄漏、样本过易、评测失真、格式过拟合或线上模板不同。要按任务切片分析 Bad Case，而不是继续盲目训练。

### 19. `★★` 如何缓解灾难性遗忘？

**口述答案：** 混入通用数据、降低学习率和步数、使用 LoRA/多任务训练，并持续跑通用能力回归。先排除 Prompt 和评测变化。

### 20. `★★★` 为什么 SFT 后还要做偏好对齐？

**口述答案：** SFT 只模仿示范，难表达多个答案间的偏好。偏好对齐优化帮助性、安全和风格，但可能带来奉承、冗长与模式化，也不会凭空增加知识。

### 21. `★★★` 经典 RLHF 三阶段？

**口述答案：** SFT、训练奖励模型、PPO 优化策略；PPO 阶段用 KL 约束模型不要偏离参考策略太远。

### 22. `★★★` DPO 与 PPO-RLHF 的区别？

**口述答案：** DPO 直接用 chosen/rejected 训练策略，不显式训练奖励模型，也无需在线 PPO Rollout，流程更简单稳定；但探索和复杂信用分配能力有限。

### 23. `★★` PPO 中 KL 系数过大或过小会怎样？

**口述答案：** 过大学不到偏好，过小会策略漂移和 Reward Hacking。调参时同时看 KL、奖励、长度、熵和人工质量。

### 24. `★★` GRPO 与 PPO 的主要区别？

**口述答案：** GRPO 对同一问题的一组回答做相对奖励归一化，省去独立价值模型；适合可验证任务，但对采样量和奖励方差敏感。

### 25. `★★★` 什么是 Reward Hacking？

**口述答案：** 模型钻奖励规则漏洞，高分却不满足真实目标。通过多维奖励、对抗测试、执行器校验、KL、人工抽检和线上监控缓解。

### 26. `★★` 合成数据的主要风险？

**口述答案：** 会继承教师偏见、放大错误、造成风格单一和自我强化。应多教师、规则验证、人工抽检，并保留真实数据锚点。

## 三、推理与部署

### 27. `★★★` Prefill 和 Decode 的区别？

**口述答案：** Prefill 并行处理输入，通常计算密集；Decode 逐 Token 生成，反复读权重与 KV Cache，常受显存带宽限制。TTFT 与 TPOT 对应的主要瓶颈不同。

### 28. `★★★` KV Cache 有什么用？

**口述答案：** 缓存历史 Token 的 K/V，避免每步重算。占用随层数、序列长度、KV 头数、头维、批量和精度线性增长。

### 29. `★★★` PagedAttention 解决什么问题？

**口述答案：** 将 KV Cache 分页管理，减少连续预留和内存碎片，并方便共享前缀和动态调度。它不消除注意力计算。

### 30. `★★★` Continuous Batching 为什么提升吞吐？

**口述答案：** 每个调度步动态加入新请求、移除完成请求，提高 GPU 利用率。代价是调度复杂和单请求延迟波动。

### 31. `★★` 三种并行如何选？

**口述答案：** 数据并行复制模型、切数据；张量并行切层内矩阵；流水线并行按层切阶段。选择取决于模型是否能放下、网络拓扑、延迟和流水线气泡。

### 32. `★★` 量化后如何评估？

**口述答案：** 不只看困惑度，还要测业务质量、长文本、代码、工具调用、速度、显存和目标硬件算子；不同量化方法在实际硬件上未必都加速。

### 33. `★★` Speculative Decoding 的条件？

**口述答案：** 小模型草拟多个 Token，大模型并行验证。只有接受率较高且验证开销低时收益明显，高并发或模型差异大时可能无收益。

### 34. `★★★` TTFT、TPOT、吞吐如何权衡？

**口述答案：** TTFT 影响首屏响应，TPOT 影响流式速度，吞吐衡量整体容量。扩大 Batch 常提升吞吐，却增加排队和 TTFT。

### 35. `★★★` OOM 如何排查？

**口述答案：** 区分权重、KV、激活、临时算子和碎片；按并发与长短请求复现；再调整最大 Token、并发、量化、GQA、分页缓存或分片。不能只重启。

### 36. `★★★` P99 延迟高怎么定位？

**口述答案：** 拆解排队、Tokenizer、Prefill、Decode、网络和工具耗时；按长度和场景切片；检查长请求阻塞、冷启动、重试和资源争用，并用 Trace 定位。

### 37. `★★` GPU 利用率低可能为什么？

**口述答案：** 流量不足、Batch 小、CPU/Tokenizer 瓶颈、通信等待、小算子、同步过多或 Decode 带宽瓶颈。要结合 SM、显存带宽、Kernel 和队列数据判断。

### 38. `★★★` 模型服务如何降级？

**口述答案：** 端到端 Deadline、限流、熔断；只重试幂等瞬时错误；必要时切小模型、缩短上下文、关闭非关键工具、只检索或转人工。

## 四、VLM

### 39. `★★★` VLM 的核心挑战？

**口述答案：** 跨模态对齐、分辨率与 Token 成本、细粒度 Grounding、OCR、时序理解和视觉幻觉。把视觉特征接到 LLM 不等于真正看懂图像。

### 40. `★★★` CLIP 的原理？

**口述答案：** 图像和文本分别编码，通过批内对比学习让匹配图文靠近、非匹配远离。适合检索和零样本分类，但细粒度空间、计数和 OCR 较弱。

### 41. `★★★` LLaVA 类模型如何连接视觉与语言？

**口述答案：** 视觉编码器产生 Patch 特征，经 Projector 映射到 LLM 嵌入空间作为视觉 Token，再做对齐训练和视觉指令微调。

### 42. `★★` 高分辨率图像怎么处理？

**口述答案：** 缩放便宜但丢小字；切 Tile 保留细节但增加 Token 并破坏全局关系。可用动态分辨率、多尺度和全局缩略图加局部块。

### 43. `★★★` 什么是视觉幻觉？

**口述答案：** 模型捏造不存在的物体、文字、数量或关系。需用 Grounding、OCR/检测器验证、反事实测试和看不清时拒答来缓解。

### 44. `★★` Grounding 如何评估？

**口述答案：** 将语言实体定位到图像区域，常用边界框 IoU、指向准确率和区域召回；还要验证实体与区域是否真正对应。

### 45. `★★` OCR 与 VLM 如何组合？

**口述答案：** OCR 负责精确文字和坐标，VLM 负责语义、版面和推理；关键字段用规则校验，不能盲信任一模型。

### 46. `★` 视频相比图片多了什么难点？

**口述答案：** 时间顺序、动作边界、长时依赖、短暂事件与音视频同步。均匀抽帧可能漏关键帧，应结合镜头、运动和检索。

## 五、RAG

### 47. `★★★` RAG 完整链路？

**口述答案：** 采集、解析、清洗、切块、Embedding、索引、查询理解、召回、重排、上下文构造、生成、引用与评估。

### 48. `★★★` RAG 与微调如何选？

**口述答案：** 动态知识、引用和权限用 RAG；行为、格式和固定任务模式用微调；两者可组合。不要用微调频繁更新事实。

### 49. `★★★` 如何选择 Chunk？

**口述答案：** 按文档语义结构切分，再用业务评测调大小和重叠。太小缺上下文，太大噪声多；重叠改善边界但增加重复。

### 50. `★★★` Embedding 模型如何选？

**口述答案：** 看语言领域、长短文本、非对称检索、速度、成本和许可；用真实查询测 Recall@K、MRR、nDCG，公开榜单只做初筛。

### 51. `★★★` 为什么混合检索？

**口述答案：** 向量检索擅长语义，BM25 擅长关键词、编号和专名；用加权或 RRF 融合后再重排，更稳健。

### 52. `★★★` Reranker 放在哪里？

**口述答案：** 在高召回初检之后，对 Query—Chunk 做精细相关性判断。候选太少漏证据，太多增加延迟，需要联合质量和 P95 调参。

### 53. `★★★` 没召回到库中答案怎么排查？

**口述答案：** 依次查入库、解析、切块、元数据权限、Embedding、Query 改写、ANN 参数和重排误杀；保存每阶段候选和分数。

### 54. `★★` 表格和 PDF 怎么做 RAG？

**口述答案：** 保留标题、页码、坐标和行列结构；表格存 Markdown/HTML 或结构化数据；图片做 OCR/VLM 描述并链接原区域。

### 55. `★★★` 多租户权限在哪做？

**口述答案：** 在服务端召回阶段按租户与 ACL 强制过滤，同时隔离缓存、日志、向量库和对象存储。不能靠 Prompt 控制权限。

### 56. `★★` 文档更新删除如何同步索引？

**口述答案：** 稳定 ID、内容哈希、版本号、幂等 Upsert、明确删除和缓存失效；再做源数据—索引对账与失败重试。

### 57. `★★★` 如何评估 RAG？

**口述答案：** 分层看解析、Recall@K/MRR、重排、Context Relevance、Faithfulness、答案正确性和引用质量；还要测不可回答问题。

### 58. `★★` 如何防御 RAG Prompt Injection？

**口述答案：** 检索内容一律当不可信数据；代码层控制权限；过滤可疑指令；限制外传；高风险动作确认；记录和验证来源。System Prompt 单防不够。

## 六、Agent

### 59. `★★★` Agent 核心组件？

**口述答案：** 模型、指令、工具、状态/记忆、规划或工作流、执行器、权限、安全、可观测与评估。

### 60. `★★★` ReAct 的优缺点？

**口述答案：** 推理—行动—观察循环能利用外部信息并展示轨迹；缺点是成本高、错误累积、容易循环和受恶意工具内容影响。

### 61. `★★★` Function Calling 的边界？

**口述答案：** 模型只生成工具与参数建议；应用必须负责 Schema、业务校验、授权、执行、幂等和审计。合法 JSON 不等于合法业务操作。

### 62. `★★★` 如何防止 Agent 死循环？

**口述答案：** 最大步数、时间、Token 和费用预算；动作去重；检查状态是否有进展；连续相同错误熔断并转人工。

### 63. `★★★` 工具失败什么时候重试？

**口述答案：** 幂等的瞬时错误可有限退避重试；参数、权限和永久业务错误不重试。非幂等写操作必须有幂等键或状态查询。

### 64. `★★★` Agent 副作用如何回滚？

**口述答案：** 用状态机和 Saga 记录步骤；能逆转则补偿，不能逆转则人工处理；恢复时从最后已提交状态继续，不能重放副作用。

### 65. `★★★` 哪些动作需要人工确认？

**口述答案：** 转账、下单、删除、发布、外发消息、权限变更和敏感数据访问。确认时展示最终目标、参数和影响，参数变化需重新确认。

### 66. `★★` Agent 记忆如何设计？

**口述答案：** 短期记忆保存任务状态，长期记忆保存稳定偏好；记录来源、置信度和过期，允许用户查看删除，避免错误摘要长期污染。

### 67. `★★★` 为什么生产 Agent 常用状态机？

**口述答案：** 状态机让路径、允许动作、恢复和审计可控；模型只在语义节点决策。高风险业务不应完全依赖自由 ReAct。

### 68. `★★` 什么时候用多 Agent？

**口述答案：** 只有角色需要不同工具、上下文或真正可并行时使用。否则单 Agent/工作流更简单；多 Agent 会增加冲突、通信、延迟和评估成本。

### 69. `★★` MCP 解决什么、不解决什么？

**口述答案：** MCP 标准化工具和资源连接；不自动解决工具质量、权限、事务、Prompt Injection 与 Agent 可靠性。

### 70. `★★★` 如何调试 Agent？

**口述答案：** 用 Trace 记录模型/Prompt、工具 Schema、每步输入输出、状态、错误、Token、费用和延迟；先分类为规划、选工具、参数、执行、观察或停止失败。

## 七、评估、安全与项目深挖

### 71. `★★★` LLM-as-a-Judge 有哪些偏差？

**口述答案：** 位置、长度、风格和同源模型偏差。可交换顺序、匿名、多次评审、明确 Rubric，并用人工样本校准。

### 72. `★★★` Agent 为什么更难评估？

**口述答案：** 它有多步决策和环境副作用，同一任务可有多条路径。除成功率，还看工具正确、步骤、成本、延迟、安全、恢复和运行方差。

### 73. `★★★` Golden Dataset 怎么建？

**口述答案：** 来自真实高价值流量与风险场景；标注答案、证据或最终状态；覆盖正常、长尾、对抗和不可回答；版本化并从 Bad Case 持续更新。

### 74. `★★★` 如何评估非确定性输出？

**口述答案：** 多次采样，报告均值、方差、Pass@k 或置信区间；Agent 要区分模型随机性与环境波动。一次成功不代表可靠。

### 75. `★★★` 为什么 System Prompt 不能保证安全？

**口述答案：** 模型不是权限系统，可能受冲突指令和上下文污染。必须用代码层鉴权、最小权限、参数校验、人工确认、隔离和审计。

### 76. `★★★` 如何防止多租户泄漏？

**口述答案：** 身份、数据库、向量库、缓存、对象存储和日志全链路隔离；服务端强制租户条件；缓存键带租户；持续做越权测试。

### 77. `★★★` 为什么项目要用 LLM？

**口述答案：** 先给规则/搜索 Baseline，再比较开放语义能力、覆盖、维护成本、质量、延迟、费用和风险。传统方法足够时就不该强用 LLM。

### 78. `★★★` 如何做模型选型？

**口述答案：** 统一任务集、Prompt 和参数，比较质量、延迟、成本、上下文、工具调用、安全和部署约束；按场景切片，选择 Pareto 最优而非只看总榜。

### 79. `★★★` 离线好、线上差如何排查？

**口述答案：** 查分布偏移、泄漏、线上模板和参数、检索/工具稳定性、Judge 偏差与延迟影响；先验证全链路一致，再回放真实流量。

### 80. `★★★` 项目连续追问如何准备？

**口述答案：** 为每个项目准备架构、个人职责、数据来源、Baseline、指标口径、P95/P99、成本、消融、最差类别、失败方案、线上结果和十倍流量方案。任何数字都要能解释分母和采集方式。
